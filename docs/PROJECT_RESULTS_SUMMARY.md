# MiniMind-V 完整项目结果汇总（数据截至 2026-08-16）

> 所有指标均由服务器端（AutoDL，单卡 RTX 4090 24GB）实测，评测口径统一：
> COCO 为官方 pycocoevalcap（val2017 全量 5000 张，含 BLEU/ROUGE-L/CIDEr/METEOR）；
> VQAv2 / OK-VQA 为官方 3-of-10 一致规则（2000 / 1000 / 5046 题）；MMBench en/dev 全量 4329 题单遍四选一。

## 一句话定位

从零搭建"预训练 → 指令微调 → GRPO/DPO 对齐 → 官方评测"完整多模态大模型训练闭环，
在单卡 24GB 上完成 65M 轻量底座全流程与 Qwen2.5-VL 3B/7B LoRA/QLoRA 规模跃迁，
并系统性诊断修复了 GRPO 奖励错位、VQA 短答案格式错位、DPO 训练塌缩三类对齐问题。

## 二、65M 全流程与 GRPO 奖励错位修复（核心研究线）

### 2.1 全流程基线（官方 COCOEvalCap，val2017 全量 5000 张）

| 检查点 | BLEU-1 | BLEU-4 | ROUGE-L | CIDEr | METEOR |
|---|---:|---:|---:|---:|---:|
| Pretrain（1.27M，仅投影） | 0.2311 | 0.0250 | 0.2160 | 0.0063 | 0.1483 |
| SFT（2.9M，解冻首尾层） | 0.2367 | 0.0237 | 0.2136 | 0.0058 | 0.1491 |
| GRPO 原版（group=4，β=0.02） | 0.1561 | 0.0067 | 0.1517 | 0.0002 | 0.1023 |
| GRPO β=0.10 | 0.2047 | 0.0136 | 0.1883 | 0.0011 | — |
| GRPO 自适应 KL + group=8 | 0.2235 | 0.0201 | 0.2007 | 0.0013 | — |
| **GRPO fix2（CIDEr 奖励 + group=16）** | **0.2392** | **0.0266** | **0.2159** | 0.0036 | **0.1529** |

### 2.2 奖励错位诊断与修复结论

- **负实验**：GRPO 原版代理奖励上升 23.5%，但官方指标全面退化（BLEU-4 0.0067、
  CIDEr 0.0002），KL 由 0.076 扩至 0.838（约 11 倍）——典型的 reward hacking；
- **修复链**：β 增大（→0.0136）→ 自适应 KL + group 8（→0.0201）→ 加 CIDEr 对齐奖励
  + group 16（→**0.0266**，超过 SFT 0.0237，+12%），KL 压至 1/18（1.23 → 0.045）；
- **诚实边界**：官方 CIDEr 0.0036 未超过 SFT，说明 n-gram 重合改善但语义多样性仍有差距，
  指向 judge 奖励 + held-out early stopping；
- **judge-GRPO 负结果**：Qwen2.5-VL-3B judge 奖励（与官方指标 Spearman r=0.38–0.48）
  训练无 KL 漂移但未超 SFT，逐样本发现模型漂移到 "As an AI language model..." 拒答腔
  ——LLM-as-judge reward hacking 案例；
- **视觉依赖验证**：correct / black / shuffled 对照证明模型确实使用视觉输入而非语言先验。

## 三、VQA 格式对齐与多任务 tradeoff（65M）

| 阶段 | VQAv2 | COCO BLEU-4 | COCO CIDEr |
|---|---:|---:|---:|
| SFT 基线 | 0.0% | 0.0237 | 0.0058 |
| VQA 专项 SFT（20k） | **31.6%** | 0（灾难性遗忘） | — |
| 混合 SFT（VQA+caption 1:1） | 20.9% | 0.0241 | 0.0067 |
| **多任务 SFT 231k（最终）** | **32.8%** | **0.2271** | **0.6395** |

- 诊断出 65M 基线 VQA 0 分是"短答案格式未对齐"而非评测 bug（强制提示词仍输出长句）；
- 数据配比消融：VQA 占比 1:3 / 1:1 / 3:1 → VQA 8.4% / 20.9% / 23.0%，caption 保持高位。

## 四、规模跃迁：3B / 7B LoRA 与效率

| 指标 | 65M 最优 | 3B LoRA | 7B QLoRA |
|---|---:|---:|---:|
| 可训练参数 | 15.9M | 37.2M（0.98%） | ~90M（NF4 1.13%） |
| 训练时长 | ~49 分钟 | 28 分钟（625 步） | 1.5 小时（8k 数据） |

- **LoRA 消融**：3B 零样本 MMBench 83.95% vs LoRA 84.9%（+0.94pp），量化"任务适配 vs 基座能力"边界；
- 7B DPO（judge 1.5k 对）：VQA 82.9%、CIDEr 0.9869，与 QLoRA 持平、能力零损失。

## 五、7B 继续预训练 → 知识型 SFT → DPO 链

| 阶段 | OK-VQA | MMBench | COCO CIDEr | 说明 |
|---|---:|---:|---:|---|
| 7B 零样本 | 42.6% | 87.34% | — | 基座 |
| 继续预训练 v2（r=128，160k caption） | 39.7% | 87.36% | 0.011 | caption 域不迁移知识问答 |
| **S4 知识混合继续预训练** | **47.6%** | **87.53%** | 0.959 | 语料-任务对齐度决定增益 |
| **知识型 SFT（9009+9009）** | **48.6%** | **87.50%** | **0.9965** | 知识能力来自任务数据 |
| DPO v3（扩偏好 + β=0.03） | 45.9% | 87.39% | 0.9547 | 规模/β 权衡 |
| DPO v6（修复后） | 47.7% | 87.32% | **0.9973** | 稳定、退化 token 0/1000 |

### DPO 塌缩修复（v5 → v6，方法论亮点）

v5（VQAv2 20k 对、β=0.02）灾难性塌缩：OK-VQA 0.0%、MMBench 54.4%，998/1000 输出退化
token "addCriterion"。逐层排查修复：

1. **数据偏置**：26.6% yes/no + 单 token 答案 → 过滤平衡为 11093 对（OKVQA 9009 + VQAv2 2084）；
2. **β 过弱**：0.02 → 0.1（原设置使 sigmoid 饱和、梯度近零）；
3. **实现 bug**：gather 用 -100 标签索引（非法内存）→ 有效 input_ids 索引 + 掩码；
4. **reference 错配**：reference 改为加载同一 SFT adapter 并冻结（policy 在其上续训）；
5. **loss 误读**：5.4 是 grad_accum 累计打印，实际单样本 DPO loss 0.693；
6. **回答掩码**：log-prob 仅统计回答 token，避免 prompt 稀释。

修复后 v6：COCO CIDEr 全场最高 0.9973，OK-VQA/MMBench 与 SFT 基本持平，无退化 token。

## 六、幻觉控制（POPE，COCO 500 图 × 6 问）

| 模型 | positive F1 | 随机负例 yes 率 |
|---|---:|---:|
| 65M multitask 基线 | 0.878 | 78.7% |
| 65M + 幻觉 SFT v1（1:3） | 0.422 | 6.0% |
| 65M + 幻觉 SFT v2（1:1 平衡） | 0.709 | 25.9% |
| Qwen2.5-VL-3B LoRA | 0.926 | 2.1% |
| Qwen2.5-VL-7B QLoRA | 0.949 | 1.9% |
| 7B + 通用 DPO | 0.952 | 2.0% |
| **7B + 幻觉 DPO（400 步）** | **0.957** | 2.6% |

结论：65M 存在清晰"数据配比 → 幻觉-召回权衡"曲线；7B 基座近饱和（随机负例 yes ~2%），
幻觉 DPO 边际提升 positive F1。幻觉控制本质是视觉接地 + 规模问题。

## 七、数据工程

- **2.9M SFT 画像**：中英均衡（en 51.2% / zh 48.5%），抽样去重率 86.1%（~14% 重复，
  给出 minhash 方案），92% 含图像占位符，答案中位 51 token；
- **231k 多任务画像**：精确重复 7 条（0.003%），minhash 近重复率 0.0016%，唯一图像 51.6%，
  跨任务同图刻意保留；
- 数据集：ALLaVA-4V（Pretrain 1.27M / SFT 2.9M）、COCO2017、VQAv2、OK-VQA、MMBench、
  幻觉/OCR/空间合成数据、DPO 偏好对（1.5k judge / 9k OKVQA / 11k 修复版）。

## 八、工程能力

- 官方 COCOEvalCap 集成（含 METEOR 与新版 JVM 兼容修复：输入消毒 + 容错解析）；
- Pretrain → SFT → GRPO → 评测一键流水线：原子断点续训、JSON 配置校验、.done 标记、CI；
- Qwen2.5-VL 训练管线：NaViT 自定义 collator、bf16、梯度裁剪、cosine 调度、QLoRA；
- black/shuffled 视觉依赖对照、逐样本预测与可视化、吞吐/显存统计；
- 单卡 24GB 全流程可复现（65M 49 分钟 / 3B 28 分钟 / 7B 1.5h）。

## 九、诚实边界（面试必提）

1. 65M 轻量底座指标用于受控对比，不代表通用能力；3B/7B 为预训练基座的 LoRA 适配；
2. GRPO 修复后 BLEU/ROUGE/METEOR 超 SFT，但 CIDEr 未超——奖励与目标仍有系统偏差；
3. judge-GRPO 与 DPO v5 均为负结果/塌缩案例，作为方法论证据而非成绩；
4. 单卡 4090，无多卡 FSDP/DeepSpeed 经验（如实标注，不强称）。
