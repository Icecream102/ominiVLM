# MiniMind-V 第二轮优化升级报告（2026-08-13）：7B QLoRA / DPO / 从零 VLM

按大厂核心算法岗面试官建议执行，全部单卡 RTX 4090 D（24GB），无分布式。

## 1. 7B QLoRA 多任务训练（P0 主线）

### 配置
- 基座：Qwen2.5-VL-7B-Instruct，4-bit NF4 QLoRA（LoRA r=32/alpha=64，
  可训练参数 95.2M / 1.13%）
- 数据：8,000 条精选多任务混合（multitask 2k + 幻觉负样本 2k +
  空间/计数 QA 2k + 合成 OCR 2k），1 epoch，batch 1 × grad_accum 8
- 分辨率 512px，梯度检查点，SDPA attention，实测单步 ~5.2s，
  总训练 ~1.5h，峰值显存 12.7GB

### 结果（65M/3B/7B 同口径对比）

| 基准 | **7B QLoRA** | 3B LoRA | 65M 最终 |
|---|---:|---:|---:|
| VQAv2（2000 题） | **82.9%** | 82.0% | 32.8% |
| 官方 COCO CIDEr | **0.9884** | 0.8364 | 0.6395 |
| 官方 COCO BLEU-4 | **0.3272** | 0.2566 | 0.2271 |
| 官方 COCO METEOR | **0.2978** | 0.2647 | 0.2364 |
| MMBench en/dev 全量 | **87.6%** | 84.9% | 26.0% |
| POPE 总体准确率 | **95.1%** | 94.2% | 37.4% |

结论：7B QLoRA 四项全面超过 3B LoRA；官方 COCO CIDEr 0.988 已接近主流
7B 全参微调水平。**单卡 24GB、8k 精选数据即可完成"7B 级 VLM 训练"**
，补上了核心岗规模硬缺口。

## 2. judge 离线偏好对 + DPO

- 偏好数据：Qwen2.5-VL-3B judge 对 7B QLoRA 策略的 VQA 回答打分，
  保留分差 ≥1.0 的 (chosen, rejected) 对，共 1,500 对（保留率约 25%）；
- DPO：手写 DPO loss（beta=0.1），策略与参考均为 4-bit，LoRA r=32
  与 SFT adapter 一致，300 步；
- 结果：VQAv2 82.9%、CIDEr 0.9869、METEOR 0.2979、POPE 94.9%——
  **与 QLoRA 完全持平，能力零损失**，证明离线偏好蒸馏在 7B 上可行。

## 3. 从零 VLM 预训练（用户新增，freeze_llm=0）

### 设计
- 文本基座仍为 MiniMind 预训练 LLM（本项目不训文本基座），但
  **VLM 侧从零开始**：随机初始化 projector + 全 LLM 解冻（freeze_llm=0），
  在 1.27M 图文对上做对齐预训练（batch 64 × 累积 2，1h40m）；
- 之后多任务 SFT（multitask + 幻觉 + 空间QA + OCR 混合，37 分钟）。

### 结果

| 基准 | **scratch_sft_vlm** | 旧 65M 最佳 | 变化 |
|---|---:|---:|---:|
| 官方 COCO BLEU-4 | **0.2485** | 0.2271 | +9% |
| 官方 COCO CIDEr | **0.7059** | 0.6395 | +10% |
| 官方 COCO METEOR | **0.2502** | 0.2364 | +6% |
| POPE 总体准确率 | **78.5%** | 37.4% | +41pt |
| POPE yes 比例 | **6.9%** | 76.7% | 校准大幅改善 |
| MMBench | 25.8% | 26.0% | 持平 |
| text-only concrete 回答率 | 100% | — | 仍会无图作答（风险保留） |

核心发现：
1. **从零 VLM 预训练（解冻 LLM）比只训投影层效果更好**——COCO 四指标
   全面超越冻结版（pretrain_full 路线），说明对 65M 容量而言，
   VLM 对齐阶段解冻 LLM 是必要的；
2. **幻觉负样本数据奏效但矫枉过正**：POPE yes 比例从 77% 降到 7%
   （准确率 37.4% → 78.5%），代价是正样本召回下降（模型偏向答 no）。
   这是"否定样本压 yes 先验"的典型过矫正案例，修复方向是正负样本
   配比调优 + 格式奖励；
3. text-only 仍 100% 具体作答（无拒答），与 GRPO judge 的"全拒答"
   形成对照：**两种极端之间的平衡点是后续对齐工作的目标**。

## 4. 任务面与数据工程新增

| 数据 | 规模 | 说明 |
|---|---:|---|
| 幻觉 QA（POPE 同款协议） | 58,226 条 | COCO2017 train 实例标注，正负均衡 |
| 空间/计数 QA | 55,782 条 | 位置（left/right/top/bottom/center）+ 计数 + 存在性 |
| 合成 OCR | 6,000 训练 + 300 评测 | PIL 渲染，自包含，无外部下载 |
| 偏好对（judge 3B） | 1,500 对 | 分差 ≥1.0，chosen/rejected |

## 5. 评测体系升级

- **POPE 约束解码 + 校准**：限制首 token 为 yes/no（多候选 token 聚合），
  输出 ECE / AUROC / 置信度：

  | 模型 | 总体准确率 | ECE | AUROC |
  |---|---|---:|---:|
  | 7B QLoRA | 95.4% | **0.0031** | **0.803** |
  | 7B QLoRA + DPO | 95.3% | 0.0022 | 0.776 |
  | 从零 VLM（65M） | 78.5% | 0.035 | 0.467（no 偏向） |

  7B 模型近乎完美校准；从零 VLM 的 AUROC < 0.5 量化了"否定样本
  过矫正"带来的判别力损失。
- **MMBench 按 category / L2-category 拆分**（全部评测 summary 含细分）；
- **text-only 鲁棒性**：无图输入下拒答率 / 具体作答率（幻觉风险）；
- 官方 COCOEvalCap 四指标对 7B 模型补齐 METEOR。

## 6. 对岗位要求的最终对应

| 考察点 | 最终证据 |
|---|---|
| 规模 | 7B QLoRA 全基准（CIDEr 0.988 / MMBench 87.6%），单卡 24GB |
| 训练配方 | 8k 多任务混合配方 vs 3B/65M 同口径对比 |
| 数据工程 | 幻觉/空间/OCR 数据构建 + 画像 + 去重论证 |
| RLHF | GRPO 奖励错位修复链 + judge 奖励相关性 + DPO 零损失 |
| 从零预训练 | freeze_llm=0 全解冻 VLM 预训练（超越冻结版） |
| 研究素养 | 幻觉过矫正、judge reward hacking、text-only 风险全部如实呈现 |

## 7. 诚实边界

- 7B QLoRA 仅 8k 样本 1 epoch，非全量多任务；更大数据/更久训练可再涨；
- POPE yes 比例 6.9% 是过矫正（no 偏向），需配比调优；
- text-only 无拒答能力（幻觉风险保留）；
- 从零 VLM 的文本基座仍是预训练 MiniMind，不是从零训文本模型；
- 多卡分布式仍未实操（唯一保留缺口）。
