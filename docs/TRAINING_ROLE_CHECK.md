# 实验梳理与多模态大模型算法训练岗符合度检查（2026-08-12）

## 一、实验全景梳理

### 主线：65M 轻量 VLM 完整训练闭环

| 阶段 | 配置 | 关键结果 |
|---|---|---|
| Pretrain | 1.27M 图文，2 epochs，freeze_llm=2 | 投影层收敛；官方 BLEU-4 0.0250 |
| SFT | 2.9M 混合指令，2 epochs，freeze_llm=1 | BLEU-4 0.0237 |
| GRPO | 5000 步；原版/固定 beta/自适应 KL/group16+CIDEr 奖励 | 官方 BLEU-4 0.0067 → 0.0266（超 SFT） |
| 评测 | 官方 COCOEvalCap（val2017 全量）+ VQAv2 + black/shuffled 对照 | 完整四维度证据链 |

### 关键研究问题与修复链

1. **GRPO 奖励错位**：reward +23.5% 但 CIDEr 退化、KL 扩大 11× → 诊断（KL 窗口统计、black/shuffled 对照）→ 修复（自适应 KL + group 4→16 + CIDEr 对齐奖励）→ 官方 BLEU-4 超 SFT。
2. **VQA 格式错位**：准确率 0 → 诊断（模型不输出短答案）→ VQA 专项 SFT 31.6%（暴露灾难性遗忘）→ 混合 SFT 20.9% 且 caption CIDEr 0.0067 全场最优。
3. **架构消融方法学**：64k 短程训练下三种架构均输出中文（对齐未收敛），结论转为“训练量/对齐是评测有效性的前提”。

### 规模实验：Qwen2.5-VL-3B + LoRA

- 训练：VQA 20k、LoRA r=16（37.2M 参数/0.98%）、625 步、28 分钟、单卡 24GB。
- VQAv2 82.0%（65M 20.9%）；官方 COCO CIDEr 0.8364（65M 0.0067）、BLEU-4 0.2566。

### 数据工程

- sft_i2t 画像（10 万抽样）：中英均衡、去重率 86.1%、92% 含图、答案中位 51 token；
- vqa_sft 画像：问答均衡、图像中位 14KB；
- 配比消融：VQA:caption = 1:3/1:1/3:1 → VQA 8.4%/20.9%/23.0%，caption 保持高位。

## 三、结论

当前项目对**多模态模型训练/对齐方向的中级岗（1–3 年）匹配度较高**，核心证据链完整：
方法论（假设→证伪→诊断→修复）在 GRPO 与 VQA 两条线上都有正结果闭环，且具备 3B 规模训练与数据工程证据。

距资深岗/核心训练岗仍差三块硬证据（按优先级）：
1. 多卡分布式训练（FSDP/DeepSpeed）——需多卡环境；
2. MMBench/更多综合基准——数据/磁盘就绪后即可补（脚本已写好）；
3. 7B+ 全参或大规模预训练——需更多算力/磁盘。
