## 2. 训练岗招聘要求对照

| 岗位要求 | 项目证据 | 判定 |
|---|---|---|
| 完整训练闭环（预训练/微调/对齐/评测） | Pretrain→SFT→GRPO→官方评测全流程 | ✅ 强 |
| 训练配方设计（数据配比、调度、优化器） | 配比消融、cosine+warmup、梯度裁剪、bf16 | ✅ 强 |
| RLHF/GRPO 对齐经验 | 完整 GRPO 实现 + 奖励错位诊断修复 | ✅ 强 |
| 规模训练（≥1B，LoRA/全参） | Qwen2.5-VL-3B LoRA（0.98% 参数，28 分钟） | ✅ 达标（中级） |
| 大模型预训练阶段经验 | 7B 继续预训练（LoRA r=64，125 步，lr 1e-5）+ DPO 全流程逐阶段评测 | ✅ 达标 |
| 训练工程细节（collator/精度/内存） | NaViT collator 踩坑、bf16、17.9GB 峰值 | ✅ 强 |
| 数据工程（清洗/去重/配比） | 画像、去重率统计、配比消融 | 🟡 有证据，规模级清洗待补 |
| 分布式训练（FSDP/DeepSpeed） | 无（单卡） | ❌ 缺失 |
| 综合基准（MMBench 等） | MMBench en/dev：3B 84.9%（全量）、65M 12.0% | ✅ 达标 |

## 3. 结论

- **多模态训练岗（中级，1–3 年）**：主要要求已满足——训练配方、RLHF、规模、工程细节均有可量化证据；
- **资深/核心训练岗**：缺分布式训练与更大规模（7B+ 全参/长上下文）两块硬证据；
- 面试定位：**“多模态模型训练与对齐工程师”**，用 3B LoRA 对比 + 配比消融 + GRPO 修复三个故事支撑。
