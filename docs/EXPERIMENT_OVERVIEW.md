# MiniMind-V 实验思路与预期目标（2026-08-12）

## 1. 最终目标

训练一个可以展示、复现、写进简历并支撑大厂多模态大模型算法岗面试的轻量 VLM。

“符合岗位要求”在本项目语境下被拆成五条可验收标准：

1. **完整训练闭环**：Pretrain → SFT → GRPO → 评测，单卡可复现；
2. **官方评测口径**：COCOEvalCap（val2017 全量）可比数字，而非自研指标自说自话；
3. **研究思维证据**：能诊断“代理奖励上升但能力下降”的奖励错位，并提出/验证修复假设；
4. **工程可信度**：原子断点续训、一键恢复、CI、实验配置校验、结果自动汇总；
5. **诚实边界**：65M 轻量底座、受限评测集、负实验结果如实呈现，不做夸大表述。

## 2. 实验思路（假设驱动链）

整个项目是一条“假设 → 验证 → 证伪 → 诊断 → 修复”的链条，每一步都有明确问题：

| # | 假设 | 实验 | 结论 |
|---|---|---|---|
| 1 | 冻结视觉编码器 + 仅训投影，单卡即可完成跨模态对齐 | Pretrain：1.27M 图文，2 epochs，freeze_llm=2 | 成立：投影层收敛，官方 BLEU-4 0.0250 |
| 2 | SFT 解冻 LLM 首尾层可保留语言能力并适配图文指令 | SFT：2.9M 混合样本，freeze_llm=1 | 部分成立：BLEU-4 0.0237，METEOR 略升 |
| 3 | GRPO 可进一步提升 caption 能力 | 5000 步，group=4，beta=0.02 | **证伪**：reward +23.5% 但 CIDEr 退化、KL 扩大 11× |
| 4 | 漂移原因是 KL 约束不足 | 诊断：KL 0.076 → 0.838，black/shuffled 对照 | 确认：奖励与评测指标错位 |
| 5 | 增大 beta 可缓解 | GRPO beta=0.10 | 部分恢复：官方 BLEU-4 0.0067 → 0.0136 |
| 6 | 自适应 KL + 更大 group + 奖励重配可进一步恢复 | GRPO 修复版（group=8） | 官方 BLEU-4 0.0201（SFT 的 85%），KL 压到 0.07 |
| 7 | **CIDEr 对齐奖励 + group=16 可超过 SFT** | GRPO fix2 | **成立**：官方 BLEU-4 0.0266 > SFT 0.0237（CIDEr 0.0036 未超，如实记录） |
| 8 | linear/MLP/视觉解冻存在可比的架构差异 | 64k 子集短程消融 | **证伪（方法层）**：训练量不足时全部输出中文，指标不可比 |
| 9 | 内部指标与官方口径一致 | 官方 COCOEvalCap 全量评测 | 方向一致但绝对值不同，需以官方为准 |

## 3. 已完成实验与结果（2026-08-12 早间）

### 3.1 全流程基线（官方 COCOEvalCap · val2017 全量 5000 张）

| 检查点 | BLEU-1 | BLEU-4 | ROUGE-L | CIDEr |
|---|---:|---:|---:|---:|
| Pretrain | 0.2311 | **0.0250** | **0.2160** | **0.0063** |
| SFT | 0.2367 | 0.0237 | 0.2136 | 0.0058 |
| GRPO 原版 | 0.1561 | 0.0067 | 0.1517 | 0.0002 |
| GRPO beta=0.10 | 0.2047 | 0.0136 | 0.1883 | 0.0011 |
| GRPO 自适应 KL | 0.2235 | 0.0175 | 0.2007 | 0.0013 |
| GRPO 修复版（group=8） | 0.2262 | 0.0201 | 0.2016 | 0.0016 |
| **GRPO fix2（group=16 + CIDEr 奖励）** | **0.2392** | **0.0266** | **0.2159** | 0.0036 |

### 3.2 GRPO 修复（内部 COCO500 对照）

| 指标 | GRPO 原版 | 修复版 | 变化 |
|---|---:|---:|---:|
| BLEU-4 | 0.0104 | 0.0270 | +160% |
| METEOR-exact | 0.2012 | 0.2815 | +40% |
| ROUGE-L | 0.1638 | 0.2273 | +39% |
| CIDEr | 0.0003 | 0.0035 | +10× |
| 末步 KL | 1.2291 | 0.0688 | 压至 1/18 |

fix2（内部 COCO500）：BLEU-4 0.0410、METEOR-exact 0.3093、ROUGE-L 0.2539、CIDEr 0.0065、末步 KL 0.0449——官方 BLEU-4/ROUGE-L 与内部多数指标均超过 SFT。

### 3.3 架构消融（方法学结论）

三种架构（linear、MLP、MLP+视觉解冻 2 层）在 64k 子集短程训练后全部输出中文描述，
英文 COCO 指标趋近于零。结论：**架构对比必须先满足对齐收敛条件**；本消融作为
“训练量/语言对齐对评测有效性的影响”证据记录，不作为架构优劣结论。
